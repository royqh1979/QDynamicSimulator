# 贝塞尔控制几何重构计划

创建时间：2026-11-27 01:29:06 +0800

状态：已完成并合并；专项测试、profile 与 Release/Debug 全量回归均通过

## 目标

分离贝塞尔曲线的数学端点与可见端点。数学路径以端点实体的 center 为 P0/P3，辅助线连接实际 P0/P3 与控制点；绘制和端点句柄使用同一原始曲线在实体边界处裁剪后的子曲线。不得把边界端点重新代入新的贝塞尔曲线冒充原路径。

## 范围与方法

- RoutedItem 内部统一生成原始控制点序列，显式区分原始路径与可见路径。
- 对二次/三次贝塞尔使用参数求值和 de Casteljau 分割，在原始曲线上取得起止参数，不以显示端点重建曲线。
- 端点实体使用实际 shape 判断曲线进入/离开边界；实体 shape 必须与实际绘制外形一致。Flow 以独立阀门 sceneShape 裁剪，不使用可点击管线。
- 若端点裁剪区域重叠导致起止参数反转，保留完整原始曲线，不生成空路径。
- 解析求值避免采样时分配向量；每条曲线只构造一次场景轮廓，可见路径按 Route、端点和预览状态缓存。
- 端点预览侧以预览位置为原始端点且不裁剪该侧，另一侧仍按实体边界裁剪。
- 辅助线使用原始端点和控制点；端点句柄继续使用可见路径首尾；箭头沿可见路径末端切线。
- 不修改 Route 持久化、相对控制点、撤销/重做、XMILE 或 Cloud 语义。

## 步骤

2. 实施统一原始路径、实际 shape 和曲线裁剪，迁移箭头及绘制边界。

4. 依次执行 Release、Debug 全量回归并自审。

## 验收边界

- 辅助线两端分别是实际数学端点和实际控制点，不是可见边界端点。
- 可见路径是原始贝塞尔的真实子曲线；控制点不变时，任意可见采样点位于原始曲线上。
- 端点句柄、箭头、Flow 双线和阀门仍使用可见路径，重连和 undo/redo 不回归。
- 不改变连接线在实体上方的既有叠放规则；辅助线延伸至实体内属于预期行为。
- 所有新增场景进入正式测试，profile 记录原始路径与裁剪联合计算结果。
