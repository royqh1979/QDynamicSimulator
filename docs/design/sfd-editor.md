# SFD 查看与编辑器设计

## 1. 范围

本文列出 SFD 查看、编辑、连接线和模型文件管理所需的完整功能，并给出实施顺序。范围不包含仿真、结果图表、CLD、Vensim 导入和敏感性分析。

当前阶段只要求单文档、单视图。多文档标签页和 XMILE 多视图均暂缓；XMILE 多视图是同一模型的多个布局，不是多文档。

## 2.1 最小可用交互约定

概念以 [Vensim、XMILE 与本程序概念对应](vensim-xmile-mapping.md) 为准；原始依据保存在 `docs/references/`。

- 左侧提供可隐藏的“绘图元素”面板。存量、辅助变量、常量、Data（数据）、云团和注释通过拖放创建。
- 分隔符后提供“流量（Rate）”和“箭头（Arrow）”两个路由工具；条目可选中但不能作为普通节点拖放。面板条目、工具按钮和菜单项使用极简 SVG 图标，顶层主菜单只显示文字，不设置图标。
- 默认工具为选择工具。选择工具下单击只选择对象，拖动对象只移动，不得创建新元素。
- Arrow 通过“左键按住源对象→拖动橡皮线→释放到目标对象”创建；释放到无效目标时不修改文档。
- Rate 除实体间拖拽外，还允许从任意空白位置开始、在任意空白位置结束。每个空白端在释放时自动创建普通 Cloud，已有 Cloud 则复用；Cloud、Flow 和路径作为一次原子编辑提交，取消时不留下对象。
- 连线过程中显示实时预览；Esc 或右键取消；每次创建结束后回到选择状态。

### Rate 与 Arrow 的区别

- Flow 对应 Vensim Rate，是 Model 中的独立语义实体，具有名称、方程、单位、端点、管线和阀门；不是 Connector。
- Rate 工具一次创建完整 Flow 实体，直接连接 Stock/Cloud；不得用“流量节点 + 两条物料连接”拼装，也不存在独立 MaterialFlow 工具。
- Arrow 对应 DiagramDefinition 中唯一的 Connector 类型，表示因果/信息关系；接入 Comment Junction 时仍只是展示对象。
- XMILE 中 Flow 保存为 `<flow>` 和 `<eqn>`，Stock 的 `<inflow>`/`<outflow>` 引用 Flow；Arrow 保存为 view `<connector>`，不得写成存量流入/流出。
- Flow 仅支持 Straight/Bezier，默认 Straight；Arrow 可支持 Straight/Orthogonal/Bezier。

## 2. 当前基础与待修正问题

当前已具备：

- 创建存量、流量和辅助变量。
- 通用有向连线。
- 移动、框选和删除。
- 名称和方程编辑。
- 滚轮缩放。
- XMILE/XML 打开及 ZIP deflate 容器保存。
- 未保存修改提示。

后续实现前需修正两个基础问题：

1. 按 Vensim/XMILE 对应表将通用连接重构为 Flow 实体与单一 Arrow/Connector，清除旧物料流分类。
2. 将较大的固定画布改为无限或按需扩展画布，并验证 XMILE 标准兼容性和无损往返。

## 3. 完整功能列表

### 3.1 模型文档管理

- 新建、打开、保存、另存为和关闭模型。
- 保存状态、修改标记和关闭前确认。
- 保存失败时不破坏原文件。
- 最近文件列表。
- 自动保存和异常退出恢复。
- 多文档标签页及模型切换（暂缓，当前仅单文档）。
- 文件不存在、损坏、无权限和格式不支持等错误提示。
- 模型名称、说明和时间单位等基础元数据编辑。

### 3.2 画布查看

- 通过滚动条、中键或空格拖动、触摸板平移画布。
- 通过滚轮、手势和缩放比例输入缩放。
- 适应全部元素、适应选中元素和 100% 缩放。
- 无限或按需扩展画布。
- 网格显示、隐藏和网格吸附。
- 元素搜索、定位和高亮。
- 缩略导航图。
- 多选时只移动选中元素，视图操作不修改模型。
- HiDPI、深色和浅色主题下清晰可见。

### 3.3 SFD 元素

必须支持：

- 存量 Stock：矩形。
- 流量 Flow：双实线管线、沙漏形阀门和方向箭头。
- 辅助变量 Auxiliary。
- 常量 Constant。
- 数据 Data。
- 源/汇云团 Cloud，用于开放系统的流入和流出。
- 文本注释和箭头批注，不参与模型计算。

每个元素应支持：

- 创建、选择、移动、复制和删除。
- Stock、Flow、Auxiliary、Constant、Data 具有唯一且可读的 displayName；nameKey 派生用于重名和引用解析，支持中文及空格。Cloud、Comment、Connector 不需要唯一名称。
- Document 集中维护 `nameKey → EntityId` 索引，创建、改名、删除、撤销/重做和加载均保持同步；每类语义变量使用独立递增计数器生成 `Stock1`、`Flow1` 等默认名称，候选冲突时继续递增。
- 所有语义变量都必须在当前视图可见；XMILE 缺少视图或缺少部分显示对象时，导入器补齐确定性布局，不得丢弃模型变量或保留不可见公式。
- 独立显示名称，名称过长时省略但可查看全文。
- 选中、悬停、错误和警告等视觉状态。
- 可选的尺寸调整和显示样式。
- 模型语义与画布位置分离。

### 3.4 连接语义

- Flow 是 ModelElement，直接持有 Stock/Cloud 端点；Arrow 是 DiagramDefinition 中唯一的 Connector 类型。
- 表达 Stock→Stock、Cloud→Stock、Stock→Cloud 的 Flow，不额外生成物料 Connector。
- Arrow 表达变量→变量、变量→Flow 的因果关系，也可连接 Comment Junction。
- 检查非法端点、自连接、重复连接和悬空引用。
- 删除 Stock/Cloud 时必须级联删除所有关联 Flow 及相关 Arrow，并通过 ChangeSet 整体撤销。
- Flow 和 Arrow 只有在两端对象一并复制时才可粘贴，不保留外部端点。

### 3.5 选择与编辑操作

- 单选、框选、多选、全选、反选和取消选择。
- 单元素及多元素移动。
- 复制、剪切、粘贴及跨模型粘贴。
- 重复创建 Duplicate。
- 左、右、上、下、水平中心和垂直中心对齐。
- 水平和垂直等距分布。
- 成组、取消分组及成组后整体移动。
- 元素层级调整，避免注释或连线遮挡。
- 无限步撤销/重做，覆盖所有模型修改。
- 快捷键及可自定义快捷键。
- 右键上下文菜单。
- Esc 取消创建、连线或拖动。

### 3.6 属性与方程编辑

- 属性编辑由独立 `PropertyPanel` Widget 承担，直接依赖 DocumentController/DiagramScene，不依赖 MainWindow；MainWindow 仅负责停靠和保存时调用 commit。名称、方程、单位和说明编辑；选中 Comment 时切换为 Content，正文修改通过 ChangeSet 撤销/重做并同步画布及 XMILE text_box。
- commit 先读取全部输入值再执行修改，避免首个 ChangeNotification 刷新输入框时覆盖其他待提交字段。
- 存量初值及净流入/净流出关系查看。
- 流量和辅助变量方程编辑。
- 常量数值和外生数据来源编辑。
- 公式语法高亮和括号匹配。
- 变量名和函数名自动补全。
- 保存方程前检查语法。
- 未定义变量、重复名称、代数环和未使用变量检查。
- 单位一致性检查和警告。
- 错误定位到对应变量或方程位置。
- Lookup 表函数数据及图形化编辑。
- 属性修改立即反映到画布，并纳入撤销/重做。

### 3.7 XMILE 与布局保存

- 以 XMILE 1.1 为目标版本，保存标准变量、方程和存量流入/流出关系。
- 保存全部元素位置、连接路由和注释；所有语义变量必须在当前视图可见，纯 XMILE 缺少视图时由导入器补齐，不得丢弃公式。
- XMILE 1.1 没有标准 `<cloud>`；Cloud 布局及其 Flow 端点引用保存在独立 workspace。标准显示对象 uid 和 workspace 文件内 uid 都只用于当次读写，加载后映射为新 EntityId。
- 保存多个视图及当前视图。
- 工作区状态放入容器内独立专有 XML。
- 打开后恢复画布位置、缩放比例和必要的窗口状态。
- 保存后重新打开，模型结构和布局一致。
- 对暂不支持的 XMILE 内容尽量保留，避免静默丢失。
- 导出剥离专有数据的纯 XMILE。
- 使用标准样例和第三方 XMILE 文件验证互操作性。
- XML、ZIP 损坏和超大文件保护。

## 4. 连接线与布线子系统

### 4.1 路由对象与模型

- Flow 与 Arrow 都是 RoutedItem，但只有 Flow 是 ModelElement；Arrow 是 Connector 视图对象。
- 两者保存起点、终点和稳定 EntityId；不设置 MaterialFlow/Information/Annotation 类型枚举。
- 校验端点合法性，禁止无效端点、自连接、重复连接和悬空引用。
- 删除 Stock/Cloud 时级联删除关联 Flow 和 Arrow。
- Flow/Arrow 仅在两端对象一并复制时粘贴，并重建内部端点映射。

### 4.2 创建与取消连接

- 从元素连接端口拖出连接线。
- 拖动时显示实时预览线。
- 悬停目标时高亮合法端口。
- 非法目标显示禁止状态及原因。
- 支持磁吸到附近合法端口。
- 创建后自动选中连接线。
- Esc、右键或点击空白处取消。
- 删除 Stock/Cloud 时级联删除关联 Flow，不保留或修复出悬空管线。

### 4.3 端点与端口

- 端点附着在元素边界，而不是简单指向中心。
- 根据相邻元素位置自动选择最优连接侧。
- 存量支持左、右、上、下和自定义端口。
- Flow 管线由两条平行实线路径组成，Connector/Arrow 使用一条实线路径；二者复用 RoutedItem 绘制、命中和箭头逻辑。Flow 箭头尺寸为 16，双实线在箭头底边前截止，短线空间不足时不绘制管线，避免穿入箭头；流量管线与沙漏形阀门形成连续图形，不出现断缝。
- 云团和辅助变量使用各自的边界交点。
- 支持拖动端点重连到其他元素。
- 重连时保留可用的中间路径。
- 同一端口有多条连接时合理错开。
- 元素移动、缩放或改名后，连接仍正确关联。
- 处理零距离、重叠元素和极端坐标，避免箭头或路径计算异常。
- 路径生成后移除重复点和零长度末段；箭头方向取最后一个有效线段，端点不得退化为目标实体中心。

### 4.4 路径形式

Flow 仅支持直线和三次贝塞尔曲线，默认直线，不使用直角自动布线。Arrow 支持直线、直角线和三次贝塞尔曲线，默认直角线。

每种路径支持：

- 显示方向箭头。
- 调整线宽、颜色和线型。
- 添加、移动和删除中间控制点。
- 拖动直线段或折线段。
- 水平/垂直约束拖动。
- 贝塞尔曲线控制手柄。
- 连接线始终位于实体上方；仅单独选中一条贝塞尔曲线时，以 2 像素深色虚线显示端点到控制点的辅助连线；多选、取消选择和区域选择过程中隐藏辅助连线与控制句柄，拖动后完整清除旧轨迹。
- 圆角折线。
- 一键重置为自动路径。
- 一键拉直或转换路径；Flow 菜单仅提供直线/贝塞尔，Arrow 另提供直角线。
- 路径锁定，移动元素时只调整必要部分。

### 4.5 自动布线

- 根据起终点自动选择路径和连接侧。
- 自动避开存量、变量、注释和文字标签。
- 元素周围保留可配置的避障间距。
- 优先短路径、少拐点和少交叉。
- 尽量避免穿过其他连接线和箭头。
- 多条平行线自动分离，避免完全重叠。
- 双向连接使用不同路径。
- 自环依赖使用独立回环路径；如果禁止自连接，则明确提示。
- 移动元素后局部重算相关路径。
- 新增、删除或缩放元素后更新受影响路径。
- 手动调整过的路径不被自动布线随意覆盖。
- 提供局部重新布线和全图重新布线。
- 无法找到无碰撞路径时，使用代价最低的次优路径，而不是连接失败。

### 4.6 选择、编辑与视觉反馈

- 连接线可单独选择和多选。
- 扩大鼠标命中区域，使细线容易点中。
- 显示选中、悬停、预览、非法和错误状态。
- 选中线时高亮相关起点和终点。
- 选中元素时高亮其上下游连接。
- 支持 Delete 删除连接。
- 提供重连、换线型、重置路径和删除等上下文菜单。
- 右键菜单包含“布线类型”子菜单，可选项为 checkable、互斥并勾选当前类型；Flow 只列出直线和贝塞尔，Arrow 另列出直角线。
- 箭头、拐点和控制点在不同缩放级别下保持可操作大小。
- 深色/浅色主题和 HiDPI 下清晰显示。
- 可选择显示连接名称或说明。

### 4.7 撤销、剪贴板与持久化

以下操作均须支持无限撤销/重做：

- 创建和删除连接。
- 重连端点。
- 移动线段或控制点。
- 修改线型。
- 自动布线。
- 批量删除元素及其连接。

XMILE 中需要保存：

- Flow/Connector 端点引用；不持久化虚构的连接类型枚举。
- 路由模式。
- 中间点和贝塞尔控制点。
- 手动/自动路径状态。
- 端口和端点偏移。
- 必要的显示样式。

打开文件后恢复同一条路径，不因重新自动计算而改变布局。

### 4.8 性能与验收

- 使用空间索引查询障碍物，避免每条线遍历全部元素。
- 拖动时只更新受影响连接，不全图重算。
- 缓存自动路径，模型未变化时直接复用。
- 大模型下限制实时重布线频率，拖动结束后完成精确计算。
- 千级元素和连接时平移、缩放和拖动保持流畅。
- 覆盖重叠元素、交叉线、双向线、长距离和极端缩放等测试场景。

## 5. 实施计划

### 阶段 1：按参照文档重构模型与路由语义

- 按 Vensim/XMILE 对应表建立 ModelElement 与 ViewElement，统一 EntityId 和 Document 所有权。
- Flow 直接持有 Stock/Cloud 端点；Arrow 使用单一 Connector，不设置物料/信息/注释连接类型。
- Cloud、Comment 移出仿真变量集合；Constant/Data 作为语义变量分类。
- 建立 displayName/nameKey、中文名称、合法端点、级联删除和 ChangeSet 撤销规则。

完成标准：能准确表达典型水箱、人口、库存和 SIR 模型的 SFD 结构。

### 阶段 2：完成查看和基础编辑体验

- 实现画布平移、适应元素、100% 缩放和按需扩展。
- 增加网格、吸附、完整选择操作和 Esc 取消。
- 完善元素绘制、连接样式和选中状态。
- 实现连接选择、删除和重连。

完成标准：仅使用鼠标和键盘即可顺畅查看、创建和调整中小型 SFD。

### 阶段 3：建立统一编辑命令体系

- 所有修改通过可撤销命令执行。
- 实现无限撤销/重做。
- 实现复制、剪切、粘贴和 Duplicate。
- 实现对齐、分布、成组和取消分组。
- 复合操作作为一次撤销单元。

完成标准：任意编辑序列都能可靠撤销至打开状态，再完整重做。

### 阶段 4：完善属性和静态检查

- 扩展属性面板：单位、说明、初值和常量值。
- 加入方程高亮、补全和括号匹配。
- 实现名称、语法、未定义变量、代数环和单位检查。
- 增加 Lookup 数据及图形编辑器。
- 将错误定位到画布元素和方程。

完成标准：常见建模错误能在保存或运行前准确定位，不产生静默无效模型。

### 阶段 5：完成连接线基础闭环与手动编辑

- 完成连接类型、端口、创建预览、选择删除、直线/直角线和移动跟随。
- 实现重连、控制点、拖动线段、曲线、路径锁定和重置。
- 将连接操作全部接入撤销/重做和 XMILE 持久化。

完成标准：能创建、重连、删除和调整路径；移动元素后正确跟随；撤销/重做可靠；保存重开后路径不变。

### 阶段 6：完成 XMILE 无损往返和文档管理

- 保存完整布局、路由控制点和注释；XMILE 多视图暂缓。
- 增加独立工作区 XML。
- 验证第三方 XMILE 样例及纯 XMILE 导出。
- 增加导入验收：无 views、有部分视图、Flow 无 pts、Flow 未被 Stock 引用四类文件均不得丢失公式；导入后所有语义变量可见，开放端具有 Cloud，稳定 Document 无零端点。
- 增加命名验收：nameKey 索引在加载和编辑后完整一致，默认名称遇到用户改名或导入占名时递增跳过，undo/redo 恢复原名称与索引。
- 增加最近文件、自动保存和崩溃恢复；多文档暂缓。
- 对不支持内容制定保留或明确警告策略。

完成标准：打开→修改→保存→重开后结构与布局一致；原文件不会因保存失败而损坏。

### 阶段 7：自动布线、效率功能与最终验收

- 使用空间索引实现自动选侧、障碍避让、平行线分离和局部重布线。
- 实现交叉优化、全图重新布线和路径缓存。
- 增加搜索定位和缩略导航图。
- 完成主题、HiDPI、快捷键自定义和中英文界面。
- 进行大模型性能分析与优化。
- 完成自动化测试和三平台 CI 验收。

最终完成标准：必选功能全部可用，XMILE 往返无损，撤销体系完整，典型模型编辑流程顺畅，千级元素平移缩放达到约 30 FPS，万级变量模型打开目标小于 3 秒。
