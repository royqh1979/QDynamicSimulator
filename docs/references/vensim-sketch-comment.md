# Vensim Sketch Comment

来源：https://www.vensim.com/documentation/22940.html

本文件保存通过页面读取工具取得的正文，供离线核对。

The Sketch Comment tool class contains only a single member. It allows you to add commentary, graphics and junction nodes to a view. The Sketch Comment tool is different from the Variable tools. Comments added to the model are not part of the model structure. Comments are only used for the purposes of presentation. To add a comment to a view select the Comment tool and click on a blank part of the view (off any words or arrows). The Comment Options dialog, which is discussed in more detail later in this chapter, will open.

Type in a comment, or select a shape or graphical form to place on the screen, and then click OK. The comment will appear on the sketch. You can move it around and operate on it just as you could any other word. If you check the Use as Arrow Junction checkbox, you can also draw arrows into it and out of it.
